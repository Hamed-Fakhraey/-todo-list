# 📝 Modern To-Do List Application

> A sleek, minimalist, and responsive task management web app built with Vanilla JavaScript, HTML5, and CSS3.

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Try%20Now-blueviolet?style=for-the-badge&logo=google-chrome)](https://hamed-fakhraey.github.io/todo-list/)
[![Vanilla JS](https://img.shields.io/badge/Vanilla-JavaScript-yellow?style=for-the-badge&logo=javascript)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)

---

## ✨ Features

- ➕ **Add & Manage Tasks:** Easily schedule your day with custom dates and descriptions.
- 📊 **Real-time Task Counters:** Live updates for Total, Active, and Completed tasks.
- 💾 **Persistent Storage:** Integrated with `localStorage` so tasks remain saved after refresh.
- 🎨 **Modern Glassmorphism UI:** Soft shadows, purple aesthetic gradient, and clean typography.
- 📱 **Mobile Friendly:** Fully responsive on all screen sizes.

---

## 🛠️ Built With

- **HTML5** & **CSS3** (Flexbox & CSS Variables)
- **JavaScript (ES6+)** for DOM manipulation & LocalStorage state handling
